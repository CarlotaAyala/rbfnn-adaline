# 🧠 RBF Neural Network with ADALINE

Implementation of a **Radial Basis Function Neural Network (RBFNN)** in Python, combining **K-Means clustering**, Gaussian radial basis functions and an **ADALINE** output layer.

The project approximates a nonlinear two-dimensional function and evaluates different numbers of hidden RBF units to identify the configuration with the lowest Mean Squared Error (MSE).

---

## 🎯 Project Overview

The objective of this project is to build and evaluate a Radial Basis Function Neural Network from its main components.

The network learns to approximate the function:

```text
f(x, y) = sin(sqrt(x² + y²))
```

A synthetic dataset of **3000 two-dimensional samples** is generated in the interval `[-5, 5]`.

The target values are normalized to the range `[-1, 1]` before training.

Several RBFNN configurations are then trained using different numbers of hidden neurons:

```text
60, 80, 90, 100, 110, 120 and 140
```

The model with the lowest training **Mean Squared Error (MSE)** is selected and used to approximate the original function.

---

## 🧠 How the RBF Neural Network Works

The network is composed of three main stages:

1. **Input layer**  
   Receives the two input variables `x` and `y`.

2. **RBF hidden layer**  
   Uses Gaussian radial basis functions centered at representative points obtained through K-Means clustering.

3. **Output layer**  
   Uses an ADALINE model to combine the activations generated by the hidden layer.

The complete pipeline is therefore:

```text
Input data
    ↓
K-Means clustering
    ↓
RBF centers
    ↓
Gaussian activations
    ↓
ADALINE
    ↓
Prediction
```

---

## 🔵 RBF Hidden Layer

The centers of the radial basis functions are obtained using **K-Means clustering**.

In `RBFNN.py`, the implementation uses:

```python
from sklearn.cluster import KMeans
```

The number of clusters is equal to the number of hidden neurons in the network.

After clustering, each cluster center becomes the center of one Gaussian radial basis function.

For an input point `x` and a centroid `c`, the activation is calculated as:

```text
exp(-||x - c||² / (2σ²))
```

where `σ²` controls the width of the radial basis functions.

The project estimates a common variance using the average squared distance between each training sample and its assigned centroid.

---

## 📍 K-Means

The repository contains two approaches related to K-Means.

### `Kmeans.py`

This file contains a custom implementation of the K-Means algorithm.

It includes:

- Random centroid initialization.
- Euclidean distance calculation.
- Assignment of samples to their nearest centroid.
- Recalculation of centroids.
- Iteration until the clustering error stabilizes.

### `RBFNN.py`

The final RBFNN implementation uses the `KMeans` implementation provided by **scikit-learn** to calculate the hidden-layer centers.

Therefore, `Kmeans.py` demonstrates a manual implementation of the clustering algorithm, while the final neural network relies on scikit-learn's implementation.

---

## 📈 ADALINE Output Layer

The output layer is implemented in:

```text
Adaline.py
```

The **Adaptive Linear Neuron (ADALINE)** receives the Gaussian activations generated by the RBF layer and learns the final output weights.

The model uses:

- Learning rate: `0.0005`
- Training epochs: `500`
- Randomly initialized weights
- Batch weight updates
- Mean Squared Error as the training error metric

The prediction is calculated as:

```text
prediction = X · W + bias
```

During every epoch, the weights are updated according to the prediction error.

---

## 🔬 Model Selection

The main script evaluates several network sizes:

```text
[60, 80, 90, 100, 110, 120, 140]
```

For each number of hidden neurons:

1. A new RBFNN is created.
2. K-Means determines the RBF centers.
3. Gaussian activations are calculated.
4. ADALINE is trained using the transformed input.
5. Predictions are generated for the training samples.
6. The Mean Squared Error is calculated.
7. The configuration is compared with the best result obtained so far.

The network with the lowest MSE is stored as the final model.

---

## 📊 Visualization

After selecting the best network, the project generates a two-dimensional grid of input points.

The trained RBFNN predicts the function values over this grid.

Two 3D surfaces are then displayed:

- **Original function**
- **Function estimated by the best RBFNN**

This provides a visual comparison between the true nonlinear surface and the approximation learned by the neural network.

│
├── Adaline.py
├── Kmeans.py
├── Main.py

└── README.md

Implements the ADALINE output model, including training, prediction and MSE tracking.

### `Kmeans.py`

Contains a custom implementation of the K-Means clustering algorithm.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/CarlotaAyala/rbfnn-adaline.git
```

2. Enter the project directory:

```bash
cd rbfnn-adaline
```

3. Install the required dependencies:

```bash
pip install numpy pandas matplotlib scikit-learn
```

4. Run the main script:

```bash
python Main.py
```

The program will train several RBFNN configurations, print the MSE obtained by each one and display the original and predicted surfaces.
